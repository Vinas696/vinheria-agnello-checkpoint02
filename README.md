# Site da Vinheria Agnello

Site desenvolvido com base no Caso da Vinheria Agnello.

# Sobre o projeto:

A Vinheria Agnello é uma loja de vinhos familiar, que atua há mais de 15 anos em São Paulo apenas com uma loja física. Dirigida por Giulio e sua filha Bianca, a vinheria é reconhecida pelo atendimento consultivo especializado, em que vendedores orientam os clientes sobre uvas regiões, rótulos e harmonizações. Com o impacto da pandemia na movimentação da loja física, os proprietários decidiram investir no desenvolvimento de um site, buscando levar para o ambiente digital a mesma experiência de consultoria oferecida presencialmente.

A funcionalidade principal desse site é um sistema básico para cadastro e análise de vinhos artesanais da Vinheira Agnello.

Este é um projeto desenvolvido para a disciplina Web, que vai utilizar as linguagens HTML, CSS e JavaScript.

# Estrutura do projeto:

```
_vinharia-agnello_/
│
├── index.html                                    
├── README.md
├── src/
│   ├── assets/
│   │   └── imgs/  
│   │       └── vinhos.png
│   ├── css/                                        
│   │   └── style.css                               
│   ├── js/
│       └── script.js                               
                     
```
-index.html: página inicial (mini apresentação);

-imgs/: imagem utilizado no index.html;

-style.css: folha de estilos utilizado no index.html;

-script.js: script que utiliza `prompt()`, `alert()` e `console.log()`, além de funções (`function`), estruturas de repetição (`while`) e estruturas condicionais (`if` e `else`). O código respeita o escopo das variáveis, onde sua finalidade é realizar o cadastro, a validação, a manipulação e a apresentação de informações sobre os vinhos;
